# logistica-automacao-triagem-python
Script desenvolvido para otimizar o fluxo de auditoria em Centros de Distribuição de grande volume (ex: Cajamar). O sistema processa cargas de devoluções, decide o destino final do produto e dispara alertas automáticos.
Como testar este projeto:

Baixe os arquivos deste repositório (Botão "Code" -> "Download ZIP" ou via comando git clone).

Abra a pasta no seu VS Code.

Aperte o "Play" no arquivo main.py e acompanhe a mágica no terminal!
